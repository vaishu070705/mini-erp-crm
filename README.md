# Mini ERP CRM

A full-stack ERP CRM web application developed using React, TypeScript, Node.js, Express, and PostgreSQL.

## Features

- User Authentication
- Dashboard
- Customer Management
- Product Management
- Order Management
- Sales Challans
- Stock History

## Tech Stack

Frontend:
- React
- TypeScript
- Vite

Backend:
- Node.js
- Express
- PostgreSQL

Database:
- Neon PostgreSQL
